    For Project Zed, I chose to create a repertoire organizer that allows performers to organize their audition material online. As a theatre student and someone who auditions frequently in the DFW, I am always looking for better ways to organize my audition material. There are so many songs and monologues I have worked on over the years, and often I lose track of the ones I really liked because I have not found a way to organize all of my material in one place. However, the development of this app will allow me and others to do so. 

	From Projects 1-3 to now, I have made a few upgrades to show my growth in my coding abilities. Since Project 1, I have added more advanced CSS animations and transitions. An example of this is the hover feature on all buttons and folders. When you hover your cursor over the different folders, a pencil icon and a trash can icon appear. These icons allow you to either edit or delete that folder. Another hover feature is that the folders and song boxes move from their static position whenever you hover your cursor over them. This enhances the app's professionalism and makes the box the user is about to click on stand out. Another upgrade I have added since Project 1 is custom CSS variables for theming. During Project 3, we learned how to use variables in CSS to make changing colors more efficient and to implement dark mode. While I don’t include a dark mode on this site, I did use variables in the CSS to make it easy to change the colors on the page if I ever wanted to. One upgrade I learned from AI specifically was how to integrate modals. In this project specifically, there are two modals: one that creates a new folder and another that allows you to edit an existing folder. When Copilot first added them to my code in the early JS, I asked it to explain what modals are and what they do, so I could understand everything about my code. These additions enhanced the repertoire organizer all around and helped to show the progress I have made since the beginning of this class. 

	AI certainly altered the development process of this project in a few ways. Since it was the one writing the majority of the code this time, I first started by asking it to generate HTML, CSS, and JavaScript, in that order, based on my idea for the project and the project instructions. Next, I examined the page and took note of things I liked and didn’t like, so that I could ask Copilot for suggestions on how to fix the things I didn’t like. That was the main difference between other projects and this project. Since I was the one creating the project entirely instead of receiving premade code from an instructor, I was able to decide what I liked and didn’t like and create unique features to best fit my app. The thing that surprised me the most about implementing AI into my development process was how easy it made problem solving. If there was an issue with my code, I could ask Copilot to scan my code and figure out what the problem was and give me suggestions on how to fix it. This sped up the development process significantly, as I didn’t have to spend as much time scanning my code for errors myself. 
    
	If I were to do this project again, a feature I would add is some way to attach files to the song/monologue boxes. This would allow the user to link a pdf of sheet music or lines to their song or monologue. I’m not sure exactly how I would do this, but I’m sure I could get Copilot to explain how to do that and then implement it myself in the future. Since the beginning of this class, I can tell that my confidence as a developer has definitely increased. I feel more comfortable navigating VS Code, and feel confident in my abilities to create a simple and functioning website. I am excited to continue honing these skills after this class and see what else I can create.
