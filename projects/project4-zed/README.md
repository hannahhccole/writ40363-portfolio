## Project Overview

This project represents the culmination of skills learned throughout WRIT 40363, demonstrating upskilling through AI-assisted development. Project Zed is about building an ambitious web application that pushes beyond the fundamentals covered in Projects 1-3, using AI as a development partner to learn new techniques and approaches.

### What is "Upskilling with AI"?

Upskilling means:
- Taking techniques from Projects 1-3 and pushing them further
- Learning new approaches through AI collaboration
- Building features I wasn't confident to tackle before
- Refining code quality and design thinking
- Expanding technical vocabulary and problem-solving
- Gaining insight from both successes and failures

**Important:** This project values the learning journey over perfection. A partially-working app with deep reflection is more valuable than a perfect app without understanding.
